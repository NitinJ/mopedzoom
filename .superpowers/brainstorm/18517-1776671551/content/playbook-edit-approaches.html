Where should playbook editing live?

Three approaches — pick the one that feels right

A

Inline on Playbooks List

Click "Edit" on a row → the row expands in-place to show editable fields. Save collapses it back.

Pros

  • No navigation needed
  • Minimal new pages

Cons

  • Cramped for multi-stage editing
  • Complex htmx state
B

Dedicated Edit Page RECOMMENDED

Click "Edit" → navigate to /playbooks/{id}/edit with a full-page form. Save redirects back.

Pros

  • Room for all stage fields
  • Matches existing task detail pattern
  • Clean, focused editing

Cons

  • Extra navigation hop
C

Modal Dialog

Click "Edit" → a modal slides in over the current page with the form. Save closes the modal.

Pros

  • Stays on the same page
  • Feels modern

Cons

  • Modals are awkward for long forms
  • Requires more JS
  • Stage editing gets crowded
